# PandaScope 数据洞察工坊

一个受 Python Pandas 启发的中英双语、可视化驱动数据分析网站。数据在浏览器本地解析和计算，不会上传到服务器。

首页提供独立的中英双语产品封面，可直接进入示例工作台或从封面导入自己的数据。

## 主要功能

- 导入 CSV、TSV、JSON、XLSX/XLS，也可直接粘贴表格文本；内置零售经营示例数据。
- 自动识别数值、分类、日期、布尔和空字段，实时计算行列数、缺失值、重复值和数据质量。
- 可搜索、排序、分页和直接编辑的 DataFrame 表格。
- 可视化数据处理：筛选、缺失值处理、类型转换、计算列、重命名、排序、字段删除、去重和分组聚合。
- 所有数据处理步骤均保留操作历史，可一键撤销或重置。
- 描述统计、字段健康画像、异常值与偏度诊断、直方图、箱线图、分组对比、透视表热力矩阵、相关系数与相关矩阵热力图。
- 图表工坊支持柱状图、折线图、散点图、饼图、面积图、直方图、智能推荐和 SVG 下载。
- CSV / JSON 导出，以及完整的中文 / English 界面切换。
- 响应式布局，适配桌面、平板和手机。

## 本地运行

这是一个无构建步骤的静态网站。在项目目录执行：

```powershell
python -m http.server 4173 --directory dist
```

然后访问 `http://127.0.0.1:4173`。

## 文件结构

```text
dist/
  index.html     页面结构
  styles.css     视觉设计与响应式布局
  app.js         数据分析、可视化与交互逻辑
.openai/
  hosting.json   Sites 托管配置
```

XLSX/XLS 解析通过 SheetJS 的 CDN 版本完成；CSV、TSV、JSON、统计与 SVG 可视化均由项目自身代码实现。
